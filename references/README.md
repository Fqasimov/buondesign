## Reel — "Buon Design Studio / Luxury is Status"

`video/reel-luxury-is-status.mp4` — 9.9 s, 1170×2532 portrait screen recording

## Direction distilled

**Mood:** quiet luxury, warm, editorial, cinematic light, lived-in.

**Starting palette** (approximate, sampled/eyeballed from the references — refine in the design-system step):

| Token idea | Hex | From |
| --- | --- | --- |
| ink / monogram | `#2F2E25` | logo "B" (dark olive-charcoal) |
| gold | `#B79F7C` | logo "D" (brushed champagne gold) |
| cream | `#EDE6DA` | logo wall / reel walls |
| sand | `#D0C8B9` | Açıq bej |
| slate label | `#2A333C` | caption boxes in the carousel |
| aubergine | `#5A2E35` | reel sofa |
| terracotta | `#9B7562` | Solğun terrakota |
| sage | `#7C7F66` | Pastel yaşıl |
| walnut | `#5D402E` | Kasella natural |

**Type cues:** high-contrast Didone-style serif for the monogram/display; widely
tracked light sans for the wordmark and small caps lines; light transitional serif
for captions and overlays; a signature script used sparingly (tagline only).
