# Buon Design — website

Marketing/portfolio site for **Buon Design** (`@buondesign.az`), an Azerbaijani
interior · furniture · architecture studio. Taglines: "Live Beautifully",
"Luxury is Status". Site plan is still to come from the client.

Read `references/README.md` before any design work — it holds the logo, the
Instagram carousel and reel, and the palette/type direction pulled from them.

## Skills in `.claude/skills/` (see `SOURCES.md`)

Use them together:

1. **ui-ux-pro-max** / **design-system** — generate and persist the design system
   (palette, type pairing, layout pattern, UX rules). Start here.
2. **impeccable** — shape, critique, audit and polish every page; keep its anti-
   "AI slop" rules. Run `audit`/`polish` before calling a page done.
3. **emil-design-eng** + animation skills — interaction and motion craft: easing,
   durations, springs, reduced-motion, performance. Review motion with
   `review-animations`.
4. **remotion-*** — programmatic video (hero loops, reels, project showcases)
   rendered from React. Start from `remotion-best-practices`.

## Ground rules

- Content is Azerbaijani first; every font must cover ə ı ş ğ ç ö ü İ.
- Quiet luxury: restraint, generous space, editorial serif, warm light. No
  generic gradients, glassmorphism or stock-SaaS layouts.
- Respect `prefers-reduced-motion`; motion should feel calm and expensive.
